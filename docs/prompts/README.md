# Prompts que funcionam

Modelos de pedido para o Claude Code. Copie, troque o que está entre `<>` e cole na
sessão. Funcionou bem um pedido novo? Salve aqui como `<assunto>.md`.

| Arquivo                                      | Quando usar                                          |
| -------------------------------------------- | ---------------------------------------------------- |
| [`nova-tarefa.md`](nova-tarefa.md)           | Começar uma pendência de `fase-1.md` ou uma feature  |
| [`regra-de-negocio.md`](regra-de-negocio.md) | Regra de dinheiro nova ou alterada (testes primeiro) |
| [`bug-visual.md`](bug-visual.md)             | Algo estranho na tela, com print                     |
| [`retomar-trabalho.md`](retomar-trabalho.md) | Continuar trabalho de outra pessoa ou sessão         |
| [`revisao-pr.md`](revisao-pr.md)             | Revisar o PR de outro membro                         |
